
# AI Scam Email Detector 🛡️

An AI-powered email scanner that detects phishing and scam emails.

### How it works
1. Reads email subject + body
2. Scores risk based on keywords, links, and shouting
3. Returns LOW/MEDIUM/HIGH risk + reasons

### Tech Stack
- Python 3
- n8n for automation
- Telegram API for alerts

### How to use
```bash
python scam_detector.py
